# @ghostvue/nuxt

Optional Nuxt module: auto-imports headless components by default; themed wrappers and theme CSS on explicit opt-in.

Allowed workspace dependencies: `@ghostvue/vue`, `@ghostvue/themes`.

See [package boundaries](../../docs/architecture/package-boundaries.md) for
the allowed dependency graph and [AGENTS.md](../../AGENTS.md) for the
repository agent entry.
