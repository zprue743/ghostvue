# Component roadmap

Sequencing of GitHub issues [#1](https://github.com/zprue743/slop-ui/issues/1)–[#19](https://github.com/zprue743/slop-ui/issues/19) toward DataTable. Public names are `Sl*` ([ADR 0003](./adr/0003-public-component-api-conventions.md)). Every component still passes the [component gate](./agents/COMPONENT_WORKFLOW.md).

Evidence is GitHub issue text, merged `master` code, and canonical docs. Unknowns are marked. Tiers are build order, not package boundaries.

| Status      | Meaning                                   |
| ----------- | ----------------------------------------- |
| merged      | Exported from `@slop-ui/vue` on `master`  |
| in progress | Open implementation PR; not on `master`   |
| planned     | Open issue; no implementation on `master` |

`master` (`packages/vue/src/index.ts`) exports `useSlId`, `useControllableState`, `useFocusScope`, and `useRovingFocus` only. No `Sl*` component is merged.
