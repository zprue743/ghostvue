# Component roadmap

Sequencing of Linear issues ([GHO-70](https://linear.app/ghost-vue/issue/GHO-70)–[GHO-107](https://linear.app/ghost-vue/issue/GHO-107)) toward DataTable ([GHO-35](https://linear.app/ghost-vue/issue/GHO-35)). Public names are `Ghost*` ([ADR 0010](./adr/0010-rebrand-to-ghostvue.md), [ADR 0003](./adr/0003-public-component-api-conventions.md)). Every component still passes the [component gate](./agents/COMPONENT_WORKFLOW.md).

Evidence is Linear issue text, merged `master` code, and canonical docs. Unknowns are marked. Tiers are build order, not package boundaries.

| Status      | Meaning                                   |
| ----------- | ----------------------------------------- |
| merged      | Exported from `@ghostvue/vue` on `master` |
| in progress | Open implementation PR; not on `master`   |
| planned     | Open issue; no implementation on `master` |

`master` (`packages/vue/src/index.ts`) exports `useGhostId`, `useControllableState`, `useFocusScope`, `useRovingFocus`, `GhostButton`, `GhostVisuallyHidden`, and `GhostInteractiveSurface`.

## Tier 4 — data
