# Vue-first, headless-first UI.

Unstyled, accessible Vue primitives in `@ghostvue/vue`. Optional, contrast-tested
OKLCH stylesheets in `@ghostvue/themes`.

## Progressive escape hatches

Simple use should look simple; consumers meet complexity only when their interface
requires it. Configuration describes intent—not the library's nested DOM.

## Engineering commitments

`@ghostvue/vue` has no dependency edge to `@ghostvue/themes`. `defineTheme` compiles
DTCG seeds into independently tuned light and dark OKLCH ramps. Production
components ship only after passing the [component gate](/agents/COMPONENT_WORKFLOW).

## Current public surface

The landing page lists every documented `Ghost*` component from generated
manifests (same catalog as the docs sidebar). Composable exports and roadmap
sequencing toward `DataTable` are in the [component roadmap](/roadmap).

> [!WARNING]
> **Pre-release:** GhostVue is under active development. Adding or promoting a
> component requires the [component gate](/agents/COMPONENT_WORKFLOW).
