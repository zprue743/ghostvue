Add `@ghostvue/mcp`, a read-only Model Context Protocol stdio server. Its `ghostvue-mcp` bin serves `list_components`, `get_component`, `get_examples`, `search_docs`, and `get_tokens` from an asset bundle shipped in the package, so it works offline. Configure it in Cursor, Claude, or VS Code as described in the MCP server guide.
